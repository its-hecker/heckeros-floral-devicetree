# HeckerOS coral hardware tree

Hardware sources for Pixel 4 XL (coral), imported from the existing PixelOS coral tree at the immutable revision in UPSTREAM_SOURCE.json. Original licenses, hardware identity, camera service fixes, CHRE/Soli configuration and vendor interfaces are retained.

The HeckerOS product, Motion Sense/FaceID policy, Suite, GCam packaging, boot diagnostics and branding belong to [HeckerOS](https://github.com/its-hecker/HeckerOS). This tree exposes one OS BoardConfig include and does not register a second ROM product. Motion Sense country configuration is owned by the ROM.

Sync and build with the [coral local manifest](https://github.com/its-hecker/HeckerOs-localmanifest). The initial target is coral only; flame will follow after coral validation. Original upstream documentation is retained in UPSTREAM_README.md. A complete HeckerOS build and phone validation are pending.
